# 網站初始化精靈

1. 在公開模板按 **Use this template → Create a new repository**，選擇 **Private**。
2. 進入新倉庫 **Actions → 網站初始化精靈 → Run workflow**，填寫網域、站名、品牌、S3 端點、Region、Bucket 和 CDN 子網域。
3. 成功後會更新 `site.config.json`。此流程不會建立 DNS、不會建立儲存桶，也不會自動部署 Cloudflare Pages。
4. 在 GitHub **Settings → Secrets and variables → Actions** 設定 `S3_ACCESS_KEY_ID` 和 `S3_SECRET_ACCESS_KEY`。**切勿將金鑰填入初始化表單、JSON 或提交紀錄。**
5. 將私人倉庫連接 Cloudflare Pages，建置命令 `npm run build`，輸出資料夾 `dist`。
6. 在 DNS 服務商將 `cdn.example.com` 指向你設定的 CDN / 圖片服務；僅填 CDN 子網域不代表圖片會自動可用。

Backblaze B2 的 S3 相容端點範例：`https://s3.us-west-004.backblazeb2.com`，Region 為 `us-west-004`。Cloudflare R2 的 S3 端點通常是 `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`，Region 為 `auto`。

**目前圖片上傳 CLI 仍採 B2 Native API；本次初始化僅完成 S3 相容儲存設定，尚未切換上傳程式。不要將設定成功誤認為已測通 S3 上傳。**
