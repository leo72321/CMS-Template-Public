# 功能與驗收

| 模組 | 做法 |
| --- | --- |
| Post／Page | Astro 內容集合，共用欄位驗證 |
| 分類、標籤 | 固定詞彙、自動彙整與分頁、索引門檻 |
| 主題群集 | 保留主題分類與公開中心頁關聯供推薦計分；不在 POST 或 PAGE 自動插入中心連結 |
| 相關文章 | 依主題、標籤、分類加權，先排除正文已推薦的文章，總量預設四篇，可用 JSON 調整 |
| 正文連結 | Agent 判斷語意，建置驗證網址與段落 |
| SEO | 標準網址、分享預覽、結構化資料、麵包屑 |
| Sitemap | 每份預設 200 URL（可調），依 POST／PAGE／分類／TAG 拆成多份 XML，總索引 `/sitemap.xml` 統一管理；不收錄頁面排除 |
| 舊網址 | aliases 搭配網址紀錄，輸出 301 轉址 |
| 圖片 | Sharp 縮圖、B2／S3 上傳、CDN 一次 HEAD 查連結（不下載圖片） |
| 查看結構 | 中文表格與 Agent 用 JSON 索引 |

## 指令對照

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 本機開發預覽 |
| `npm run preview` | 預覽已建置的產物 |
| `npm run site:init` | 設定網域與基本資訊 |
| `npm run content:new` | 建立草稿並同步索引 |
| `npm run media:add` | 圖片縮圖、上傳、填回 |
| `npm run media:verify` | 僅供手動診斷：以 HEAD 檢查在用的遠端連結，不下載圖片內容 |
| `npm run media:verify:full` | 手動對全部使用中圖片做 HEAD 連結檢查，不下載圖片內容 |
| `npm run media:orphans` | 列出疑似未使用檔案，不自動刪除 |
| `npm run urls:update` | 檢查舊網址後更新紀錄 |
| `npm run urls:check` | 只檢查網址變更 |
| `npm run docs:update` | 更新中文結構表及索引 |
| `npm run docs:check` | 檢查索引是否最新 |
| `npm run check` | Astro／TypeScript 型別檢查 |
| `npm test` | 內容與圖片流程行為測試 |
| `npm run test:output` | 在臨時副本注入故障，確認產物驗收能攔截錯誤 |
| `npm run build` | 驗證內容、更新結構、建置及檢查 HTML |
| `npm run verify` | 型別、測試及完整建置驗收 |

## 檢查範圍

驗證標題、簡介、Canonical、索引、OG 網址、JSON-LD 格式、唯一 H1、圖片替代文字與尺寸、內部網址、段落錨點、孤兒頁、Sitemap 清單及產物大小。

孤兒頁指從首頁沿連結無法抵達的頁面。正文／中心頁連入不足另列編輯提醒，不把列表連入誤當成語意品質保證。

預算：單頁原始 HTML 80 KB、gzip 壓縮 25 KB，全站 CSS 30 KB，自家前端 JS 0 bytes。GTM 第三方下載不算自家 JS，但實際速度仍受它影響。

## 限制

- 大小驗收不是 Lighthouse（網頁評測）或 Core Web Vitals（核心網頁體驗指標）；正式站仍需量測網路、圖片與第三方追蹤。
- 索引門檻不保證排名；策略、搜尋意圖與語意品質仍由編輯判斷。
- 不驗站外連結，以免第三方暫時異常拖垮建置。
- 單一 Sitemap 上限 49,999 頁，超過會停止，屆時再分片。
- B2 行為測試使用模擬回應，實際帳號、DNS、CDN 仍需一次真實驗收。
- 圖片不刪遠端舊檔，GIF 只取第一格。
- 預約文章需重新建置，不內建排程、搜尋、會員、購物車與後台。

## POST 尾端區塊

只保留可由全站設定控制的標籤、作者卡、延伸閱讀和可個別啟用的自訂區塊。閱讀提醒、Topic 跳轉與服務卡片不再預裝在每篇文章。各元件的關閉與再次啟用、PAGE 連結、HTML 安全轉義及擴充位置詳見 [POST 頁尾設定](POST頁尾設定.md)。

## 大型網站媒體成本

5,000 個頁面與數萬個圖片物件時，媒體索引用 URL Map；上傳後僅 HEAD 一次，正常 CI 不連線重驗媒體，也不再自動安排每週巡檢。若需要排查死圖，可手動執行 HEAD。任何疑似孤兒媒體都不自動刪除，詳見 [圖片操作](圖片操作.md)。

## 自動拆分 XML Sitemap

`/sitemap.xml` 是 Sitemap Index，僅列出實際生成的 `/posts-001.xml`、`pages-001.xml`、`categories-001.xml`、`tags-001.xml` 等子檔。超過 `sitemap.maxUrls`（預設 200）自動新增下一份；不需要付費外掛。空／禁止索引站只輸出空 urlset。`robots.txt` 保持指向總索引，驗收逐檔檢查 URL 和 lastmod。操作見 [網站設定](設定說明.md)。
